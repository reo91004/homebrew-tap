# reo91004/tap

Homebrew formulae and casks.

```bash
brew install reo91004/tap/tzb
brew install --cask reo91004/tap/usagi-agent
```

- **tzb** — two-way sync of PDF highlights between Zotero and Tine. See [tine-zotero](https://github.com/reo91004/tine-zotero).
- **usagi-agent** (cask) — 화면 구석의 우사기 비서: 할 일, 브리핑, 집중하기, 실험 끝 알림(`usagi-run`). See [usagi-agent](https://github.com/reo91004/usagi-agent).
